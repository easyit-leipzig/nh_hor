# Header-/Navigationsmenü mit Menü-Fähnchen – Korrekturstand

## Verhalten

- Der normale Seitenheader und die Navigation scrollen beim Herunterscrollen aus dem sichtbaren Bereich.
- Sobald der Header vollständig verschwunden ist, erscheint rechts das Menü-Fähnchen.
- Beim Anklicken wird das Menü an der aktuellen Fensterposition von oben eingeblendet.
- Das eingeblendete Menü besitzt einen eigenen Kopfbereich mit Logo/Seitentitel, der Bezeichnung „Hauptnavigation“ und einer Schließen-Schaltfläche.
- Schließen ist über X, Escape, Klick auf den abgedunkelten Hintergrund oder Auswahl eines Menülinks möglich.

## Korrekturen dieses Stands

- Die sichtbaren Einzelpunkte beziehungsweise Listenmarker im eingeblendeten Menü wurden entfernt.
- Ein eigener Header wurde ergänzt.
- Desktop- und Mobilansicht bleiben responsiv.

## Enthaltene Dateien

- `assets/css/menu-flag.css`
- `assets/js/menu-flag.js`
- `includes/footer.php`

## Installation

Den Ordner `nh_hor` über den vorhandenen Projektordner kopieren und die enthaltenen Dateien ersetzen. Danach im Browser mit `Strg + F5` neu laden.
