# Startseiten-Slider für nh_hor

## Enthalten
- aktualisierte `index.php`
- vier optimierte WebP-Bilder unter `assets/img/hero/`
- automatische Überblendung alle 6,5 Sekunden
- Pause-/Fortsetzen-Schaltfläche
- Navigationspunkte
- Pause bei Mauszeiger, Tastaturfokus und inaktivem Browser-Tab
- Berücksichtigung von `prefers-reduced-motion`
- lokale Pfade über `app_path()` und produktive Domain-Root-Pfade

## Installation
Den Inhalt des Ordners `nh_hor` nach

`C:\xampp\htdocs\nh_hor\`

kopieren und vorhandene Dateien überschreiben. Danach im Browser `Strg + F5` drücken.

## Geänderte Datei
Nur `index.php` wird ersetzt. Die vier Bilder werden neu ergänzt.
