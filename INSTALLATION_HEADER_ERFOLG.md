# Header- und Erfolgsseiten-Update

## Enthalten

- `includes/header.php`
  - H1: „Nachhilfe mit System“
  - H2: „Nachhilfe mit Erfolg“
  - das Wort „Erfolg“ ist optisch nicht als Link markiert
  - Title-Text verweist auf den Erfolgsnachweis
- `erfolg.php`
  - transparente Darstellung der 90-%-Aussage
  - Kriterien und Einschränkungen
  - automatische Ausgabe veröffentlichter CMS-Bewertungen
  - Bewertungen erscheinen in persönlicher Ich-Form, sofern sie so im CMS erfasst wurden
- `assets/css/erfolg.css`

## Installation

1. Bestehenden Projektordner sichern.
2. ZIP in `C:\xampp\htdocs\` entpacken.
3. Vorhandene Dateien im Ordner `nh_hor` überschreiben.
4. Browser mit `Strg + F5` neu laden.
5. Prüfen:
   - `http://localhost/nh_hor/`
   - `http://localhost/nh_hor/erfolg.php`

## Wichtiger Hinweis zur 90-%-Aussage

Die Aussage darf nur öffentlich verwendet werden, solange die zugrunde liegende Auswertung dokumentiert und prüfbar ist. Die Seite enthält ausdrücklich keine Erfolgsgarantie.
